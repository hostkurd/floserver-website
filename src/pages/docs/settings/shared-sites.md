## The www folder {#www}

In **Settings → Shared sites**, choose the www folder and the PHP version, database and web server every shared site uses: Apache (so .htaccess works) or nginx.

<figure><img src="/img/docs/settings-shared.png" width="1026" height="843" loading="lazy" alt="Settings on the Shared sites page: www folder, PHP, database and web server"><figcaption>Settings → Shared sites.</figcaption></figure>

Everything starts by itself when a page is opened, and sleeps when idle.

What shared sites are, and when to make a folder a project instead: [Shared sites (www)](/docs/shared-sites/).
