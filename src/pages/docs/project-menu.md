## The menu {#menu}

<figure><img src="/img/docs/window-menu.png" width="1106" height="713" loading="lazy" alt="The right-click menu on a project, with Open in browser, Open folder, Open terminal, Open in VS Code, Copy address, Turn off, Keep running, Rename, Back up as zip, Restore from backup and Remove from FloServer"><figcaption>The right-click menu on python-app.</figcaption></figure>

| Item | What it does |
| --- | --- |
| **Open in browser** | Opens the project's address |
| **Open folder** | Opens its folder in File Explorer |
| **Open terminal** | A terminal in its folder, where `php`, `node` and the others use its versions |
| **Open in VS Code** | Opens the folder in your code editor ([Settings → General](/docs/settings/general/)) |
| **Copy address** | Puts its address on the clipboard |
| **Turn off** | Stops the project |
| **Keep running** | Keeps it awake instead of sleeping when idle |
| **Rename…** | See [Rename a project](/docs/rename/) |
| **Back up as zip…**, **Restore from backup…** | See [Backup and restore](/docs/backup/) |
| **Remove from FloServer…** | Forgets the project in FloServer |
