## Quick start {#quick}

```bash
# in a project folder
flo add
flo use php 8.5
flo start
flo env --write
```

## Terminal commands {#shims}

`php`, `composer`, `node` and the others use each project's versions in any terminal. See [Terminal commands](/docs/terminal/).
